# Reports

Pre-registrations, data notes and results. Each study was registered before
its data was read; a result report says whether the registered bar was met.
Reports quote aggregate figures.

* [`scripture-research-class-a.md`](scripture-research-class-a.md): the
  programme's pre-registration, track by track.
* `scripture-research-*-data.md`: how a hand-built table was made and checked.
* `scripture-research-results-*.md`: each track's results.
* [`scripture-lxx-bridge-measurement-2026-10-19.md`](scripture-lxx-bridge-measurement-2026-10-19.md):
  the Hebrew-to-Greek bridge's method and measurement.

The reports were written in Carestead's internal repository. Commands such
as `flock-scripture-import research ...` name Carestead's tool, which is not
published. Links to unpublished documents were removed; their names are kept
as plain text.
