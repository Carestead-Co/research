# NTVMR ledger

The INTF transcriptions the manuscript research read, one row per file: the
document id, the manuscript, the chapter or page read, its size, its sha256
and the API URL. Every file listed states CC BY 4.0 in its TEI header.
The transcriptions themselves are not copied here; fetch them from the URL.

Source: Institut für Neutestamentliche Textforschung, New Testament Virtual
Manuscript Room (CC BY 4.0).
