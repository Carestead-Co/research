# Genealogies

* `genealogies.tsv`: one row per name, in each source's own order: Matthew 1,
  Luke 3, Genesis 5 and 11, Ruth 4, 1 Chronicles, 1-2 Kings (Judah's kings),
  and Ezra and Haggai.
* `genealogy-people.tsv`: candidate identities across those rows. A note of
  HYPOTHESIS or "Single source" marks an identity the texts do not state.

Transcribed from the BSB (public domain); every name was checked against its
verse. Data note:
