# Bible research

The data behind <https://research.carestead.co/bible>.

* [`open/`](open/): CC BY 4.0. Data we wrote ourselves, and data built only
  from public domain or CC BY 4.0 sources (for example the Berean Standard
  Bible, Brenton's Septuagint, STEPBible's tagged texts, and INTF
  transcriptions that state CC BY 4.0).
* [`share-alike/`](share-alike/): CC BY-SA 4.0. Data built from a ShareAlike
  source. It is closed until a source is admitted.

## The rule between the two

Nothing in `open/` is built from anything in `share-alike/`. A result that
needs both belongs in `share-alike/`.

Carestead's products use only public domain and CC BY 4.0 data. Nothing in
`share-alike/` is used in any Carestead product, including as a setting or
threshold chosen from its results.

## What is not published here

* The Revised Common Lectionary (copyright of the Consultation on Common
  Texts) and any evaluation set drawn from it.
* Any rating by a named person, unless they have agreed in writing.
* Any church's or user's data.
* Transcriptions whose licence is "all rights reserved", or non-commercial
  without permission.
